# Weather Data Analysis and Prediction

A machine learning-powered weather forecasting application built with Flask, Pandas, Scikit-learn, and Linear Regression. This project analyzes historical weather data, trains a predictive model, and provides future temperature forecasts through a modern, weather-themed web interface.

## Features
- Historical weather data analysis
- Temperature trend prediction
- Linear Regression model training
- Flask web application
- Interactive prediction dashboard
- Responsive weather-themed UI
- Saved model using Pickle (.pkl)

## Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- HTML
- CSS

## Future Enhancements
- Weather charts and visualizations
- Multi-feature prediction (humidity, rainfall, wind speed)
- ARIMA and LSTM forecasting models
- Real-time weather API integration
- Advanced analytics dashboard
